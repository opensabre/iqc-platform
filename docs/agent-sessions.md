# 智能体会话管理

## 第一版范围

独立“会话查询”菜单提供跨智能体分页历史、智能体/会话标题/发起人账号/开始时间筛选和消息详情；智能体列表的“会话管理”保留指定智能体快捷入口。详情展示用户消息、智能体回复及每轮实际模型、耗时、实际工具名。无手动删除按钮或接口，定期清理后续规划。

已保存智能体版本的测试聊天在首轮成功后创建会话，响应返回 `sessionId`，后续请求携带此字段并追加同一会话。重新开始、切换智能体、版本、配置或关闭聊天窗口后均重置当前会话。会话详情只读，第一版不从历史详情恢复聊天。未保存配置的临时测试不入库。历史内存聊天无法补录。

只保存成功问答；模型失败不伪造回复，输入保留供重试。请求上下文上限沿用 40 条、32000 字符；最终回复可使已保存会话达到 40 条消息，达到上限后需重新开始。

## 存储和复用

`iqc_conversation` / `iqc_conversation_message` 是导入质检素材的模型，不具备智能体和版本归属。框架及共享服务没有可直接复用的智能体会话存储。新增 IQC 自有 `iqc_agent_chat_session` 表，以有界 JSON 保存消息，复用当前模型、凭据和 MCP 执行链路、IqcPage 分页及 IqcDataScope 数据范围。列表 SQL 仅取摘要，不加载消息正文或配置指纹。不保存配置快照、密钥、工具参数或结果、内部推理。

每个会话绑定智能体、版本和服务端保存配置的 SHA-256。已有上下文由服务器校验，不能任意替换之前的用户/助手消息。仅发起人可继续会话；管理员及现有数据范围规则允许的用户可读历史。会话详情同时验证 URL 智能体与记录归属。并发追加使用旧消息数条件进行乐观更新，防止覆盖已提交历史；这不保证并发请求不会产生重复模型/工具调用。模型调用期间不持有数据库事务。

## API

- `POST /api/iqc/config/agents/test-chat`：兼容现有请求，增加可选 `sessionId`；返回原回复信息及可选 `sessionId`。新保存会话必须只有一条用户消息，后续按服务器历史追加一条用户消息。临时配置不允许携带已保存会话 ID。
- `GET /api/iqc/config/agent-sessions`：跨智能体列表，可选 `agentId` 及相同分页/筛选字段。
- `GET /api/iqc/config/agents/{agentId}/sessions`：`current`、`size`（最多100）、`title`、`owner`、`startedFrom`、`startedTo`；时间采用无时区 ISO 本地时间，与现有 IQC 时间约定一致。
- `GET /api/iqc/config/agents/{agentId}/sessions/{sessionId}`：摘要与按顺序保存的消息，纯文本显示。

测试沿用 `iqc:agent:manage`；前端路由及按钮沿用 `iqc:agent:view`，各历史接口使用独立资源编码，后端仍校验数据范围。部署后须验证治理资源注册和角色 URL 授权，不能仅凭按钮权限判断接口可用。不修改共享服务或框架。

## 数据库升级

新增 MySQL Flyway DDL `V1.1.41__ddl_add_agent_chat_session.sql`，不改冻结 baseline/history，不迁移或修改客服质检素材，不写线上初始数据。先完成迁移再部署应用。回退应用时可保留表以保留历史；第一版不提供清理脚本。

## 独立查询菜单

“智能体管理 → 会话查询”，路由 `/agent-sessions`。复用现有会话列表及详情组件，增加智能体筛选与归属列；原智能体列表的快捷入口保留。新增 `GET /api/iqc/config/agent-sessions`，可选 `agentId`，缺省时跨智能体查询当前用户数据范围内的会话，始终保留相同的发起人/团队/管理员范围校验。不新增表或其他业务数据模型。

新接口资源 code 分别为 `iqc:agent-session:query`、`iqc:agent-session:agent-query`、`iqc:agent-session:detail`，对应全局列表、指定智能体列表和消息详情，防止唯一资源 code 注册覆盖原有 URL。

生产菜单来自组织中心授权树，前端不强行补入未授权菜单。具体待确认的通用菜单及授权配置见 [菜单配置提案](agent-session-menu.json)：在现有智能体管理下添加会话查询，复用智能体查看权限，菜单角色沿用智能体列表现有角色，三个 GET 资源授权沿用已有智能体查看角色。不扩大数据访问范围，不向 base-organization 增加 IQC 业务源码。

尚未修改组织中心菜单、角色或资源数据；需要依据 workspace AGENTS.md 的基础服务变更规则明确批准该具体配置后应用。独立菜单本地开发回退导航已包含新入口，生产必须完成上述授权菜单配置后显示。

独立查询菜单增量验证（2026-11-18）：前端生产构建及 9 项会话/聊天交互测试通过；后端 25 项回归通过，包含跨智能体查询仍限定发起人/团队数据范围。修正测试夹具的 Mapper 元数据初始化顺序依赖。没有变更数据库结构或线上菜单数据。
