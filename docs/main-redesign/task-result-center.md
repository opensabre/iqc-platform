# 新任务结果中心列表

`GET /api/iqc/results/business` 现在识别会话级 `TASK_PROCESSOR` 结果，读取已保存的 `output.inspectionItems` 与 `output.labels`，不再将整个处理器结果当作旧质检项数组。

- 结果数量统计目标质检项和标签，不重复统计多个引擎的投票。
- 不通过数量仅统计 KNOWN 且值为 FAIL 的质检项；错误数量统计 ERROR 目标。
- 仅 FINAL 展示最终分数，保留真实 0 分；待定和纯打标任务分数为空。
- 复用任务摘要的统计逻辑；未知格式或损坏状态拒绝展示，不降级成通过。
- 同一列表兼容已有数组格式的历史任务；沿用现有任务可见范围与分页查询。

组合任务集成验收通过真实 HTTP 查询结果中心，检查一条会话的评分、目标数、不通过数和实际执行 ID。
