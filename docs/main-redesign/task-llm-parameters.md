# 任务级大模型参数

每个LLM引擎的parameters可分别提交prompt（去除首尾空白后1–8000字符）、temperature（0–1，含0）、timeoutSeconds（1–120整数）。省略字段沿用已发布配置，旧请求兼容。其他引擎拒绝这些字段。

参数保存在现有冻结agentSnapshot.taskOverrides中，不改写已发布配置。提示词追加为本次任务指令，沿用原有结构化输出协议。模型路由对主模型和每个备用模型的副本应用温度和传输超时；旧版部署默认OpenAI模型使用独立客户端配置副本。其他不支持的默认模型明确失败，不静默忽略参数。

超时为每次模型请求的传输超时，包含重试/备用切换的总执行时间可能更长。原始输出、失败及本次参数继续按原有任务证据记录保存；无需新表、接口或基础服务改动。


## HTTP 边界回归

`TaskModelHttpParametersTest` 使用本机随机端口的模拟 OpenAI 兼容端点，
通过实际 `SpringAiLlmQualityProvider`、`SnapshotChatModelRouter` 和模型 SDK 发出 HTTP 请求：

- 主模型返回错误时，按冻结顺序调用备用模型；检查两个请求的模型名称、任务提示词及显式零温度。
- 已发布模型超时为 30 秒，任务覆盖为 1 秒；主端点延迟 3 秒时，应切换到备用模型，不能接受迟到的主模型结果。
- 旧版默认模型同样收到任务参数，原部署配置的温度和超时不被改写。

测试不依赖真实供应商、密钥或共享服务。此范围证明本地 HTTP 请求与客户端超时行为，
不代表供应商端推理质量、生产网络、总重试时限或正式应用登录链路验收。
