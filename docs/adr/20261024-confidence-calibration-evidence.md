# 原评测证据上的置信度校准

状态：分阶段实施，2026-10-24。

PRD14.3要求模型置信度校准，FusionPolicy已有校准ID/节点声明，但没有拟合产物及实际转换证据。检索拥有模块、Framework和Wiki未发现可复用的校准产物实现；现有Gold、EvaluationSampleResult校验、十箱计数及报告权限已足够提供可溯源候选，当前不新增表/API/通用资产框架。

第一步复用原始模型节点计数，对执行状态为SUCCEEDED、完整且全部样本成功的原评测报告生成十箱经验校准候选。事件为当前类型化事实完整值与已知Gold一致，不是正类概率。绑定任务/执行、数据集摘要、流水线摘要、节点定义摘要以及已校验样本原执行/Gold/实际结果摘要集合。精确整数正确数参与拟合，不从四舍五入后的诊断准确率反推样本数。

采用固定十个等宽箱，每箱至少20个已测量样本才输出经验正确率，保留六位小数；不足/空箱返回null。该阈值是保守的初始可用性下限，不是统计可靠性保证。方法简单、确定、有界，适合已有最多1000个样本的评测；不插值、不外推、不声称单调或跨部署适用。产物带原摘要、精确计数及内容摘要，转换函数只在有支持的分箱返回值。

候选不是已发布校准：拟合样本内的结果不能证明留出集质量改善，后续仍须独立验证、按当前组织数据范围读取原来源、在任务事务冻结来源和交集、核验节点/模型/Prompt/知识引用绑定后才能改变融合输入。共享Pipeline只允许精确来源引用，不能把私有Gold统计作为客户端可任意提交的“已校准”证据。当前阶段保持融合行为，真实校准运行与全链验收未完成。

后续接入约束：来源pipelineHash用于确认原评测身份；目标兼容性须比较冻结检测图/节点和实际模型调用来源，不能因从PRIORITY改为CONFIDENCE而错误要求整个融合发布Hash相同。来源授权与系数冻结在原任务事务内完成，任务组只允许取全部来源交集，历史执行只核验原冻结资料。模型自报/原始值与校准后值分别保留，运行转换应发生在条件分支/融合消费之前，缺乏分箱支持保持未知；回放须能从原始值与冻结产物复核转换。独立验证需与拟合样本区分，并分别报告可转换覆盖与误差，不能只比较经过筛选的子集后宣称全量改善。以上链路尚未实现，不据此开启默认v2或部署。

精确来源读取现复用PipelineEvaluationService的原任务/执行/报告校验：MANDATORY事务、稳定父任务锁顺序、锁定行的数据范围授权、SUCCEEDED与完整样本门槛、原候选Hash匹配、相同冻结检测图。同一执行的报告批内缓存，仅返回原服务拟合的Artifact及内部有效来源组，不接收客户端系数。尚未加入任务系数信封/当前资源授权调用边界或FusionPolicy执行引用；这些仍是后续必需工作。

任务系数冻结已编码：复用FusionPolicy可选精确引用、原任务保存边界及evaluation:report:view当前授权，将来源服务返回的系数放入私有calibrationInputs，收窄到所有来源组交集。纯校验不查询可变评测，绑定原始节点定义/产物Hash及任务负责人，保留旧构造与空引用序列化。原模型桥接已应用冻结系数并分别保留原始/校准值、产物Hash和支持状态，父轨迹边界可重算转换；原阶段拒绝由已冻结信封准入与实际转换校验替代。独立验证、实际模型绑定和发布准入仍须继续。

配对诊断已沿原报告实现：只对同一有效事实且原始/校准值同时可测、成功轨迹证明与引用产物一致的预测成对计分；两个计数器共享正确性事件与样本集。分别显示已知Gold覆盖和相对原始已测预测的可转换覆盖，空集合误差为null，差值采用after-before。当前应用产物与报告新拟合候选分开显示；不将经过筛选的配对误差下降解释为全量改善或独立验证通过。该实现复用原ConfidenceCounter与六位小数ratio，不新建存储或API。

发布隔离沿现有PipelinePublicationGateService质量/回归双执行入口接入，不增加校准表或另一套证据API。存在校准引用时，在原事务中按现有来源服务重新核验当前report:view、组织范围、来源锁和原始候选；两个验证任务的原冻结产物引用必须与当前发布引用完全一致。各拟合数据集与两个验证集分别按样本ID及已处理会话ID检查无交集，换样本版本/数据集不能绕过。此为可核验身份隔离，不证明统计独立；不对质量与回归数据集之间另加无依据的互斥要求。证据重叠或无法核验直接拒绝，管理员强制发布仅覆盖测量指标失败，不能覆盖证据真实性。尚未完成实际部署身份绑定、校准误差质量阈值或容量验收。

校准测量准入扩展现有PublicationGatePolicy可选calibration字段，旧七参构造及无字段序列化保留。PRD14.3要求校准评测、14.5要求可配置门禁，但未指定校准误差数值，因此服务端不填充隐含校准标准。引用校准产物且未配置门槛，记录CALIBRATION_POLICY失败；逐引用节点、逐QUALITY/REGRESSION执行检查最少配对样本(1–1000)、已知Gold最低覆盖(大于0且至多1)、校准Brier/ECE上限(0–1)、相同样本误差增量上限(-1–1)。空测量/不足样本/零覆盖不能通过，合法0%置信度及零误差不是缺失。增量0表示允许持平，负值要求下降，绝对误差仍单独约束；不以全部原始预测与校准子集比较。

各准入项保留actual/threshold/状态，purpose携带验证类型与节点ID，原决策摘要/发布审计存储这些测量。质量阈值失败沿PRD既有管理员原因与强制发布审计，不扩大为证据真实性覆盖。界面复用原策略编辑器；显式开启的20例/80%覆盖/Brier0.25/ECE0.1/增量0只是可编辑初值，界面明确非PRD标准或效果保证。实际业务门槛须由策略作者按风险和留出数据决定。本轮不修改Framework/表/API/默认v2，不据此宣称真实供应商模型身份或容量验证完成。

可选配置示例（仅展示字段，不构成推荐质量标准）：

```json
{"calibration":{"minimumPairedSamples":20,"minimumGoldCoverage":0.8,"maximumBrier":0.25,"maximumEce":0.1,"maximumBrierIncrease":0,"maximumEceIncrease":0}}
```

该对象嵌入已有publicationGate；六项均须显式给出，未提供calibration字段保留历史策略JSON。覆盖分母为节点相应findingCode的已知Gold，含缺失/未知/无支持分箱预测；不以已配对样本自己作为覆盖分母。错误增量来自同队列配对统计，零误差上限可配置，只有null表示未测量。发布质量和回归验证分别满足条件，不进行节点间平均以掩盖单节点失败。
