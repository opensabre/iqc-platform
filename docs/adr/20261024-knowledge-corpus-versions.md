# Knowledge Base 独立语料版本

状态：分阶段实施；2026-10-24。

需求来源：PRD10的LLM节点知识库配置及PRD17的Knowledge Base独立版本、任务版本ID/Hash冻结。Prompt指令版本已复用Skill，本域必须保存被引用的参考资料，不能把指令、会话、Gold或评测数据集改称知识库。

复用检索：拥有仓库的Agent/Skill/Selector/Dataset/Pipeline，Framework和共享服务，以及Wiki服务地图均未提供独立语料集合版本。Skill是指令/工具配置，Selector是会话选数，Dataset是评测Gold成员；这些模型不能表达独立参考文档集合及其版本身份。现有MySQL、BasePo/Mapper、IqcDataScope、JSON摘要与不可变版本/CAS发布模式足够，不需要新增基础设施或框架抽象。

因此新增iqc_knowledge_base与iqc_knowledge_base_version两张领域表。它们是语料集合的唯一持久化模型，不复制Prompt/会话/Gold，不创建通用资产或版本框架。草稿使用单调修订，发布形成不可变语料版本和内容摘要；默认停用、显式启用，后续发布不改变已经启用状态或旧引用。沿owner/group/all读取，维护操作沿现有资产的接口写权限与相同数据范围授权，冻结原归属与实际发布人；组变化只能收窄历史可见性，不接收客户端组织或租户头。

KB1（已编码）：有界纯文本语料定义、草稿/不可变版本、CAS发布与向前恢复、来源摘要、组织数据范围和可用性解析、迁移脚本及内部服务。KB1阶段不暴露缺少权限注册/敏感投影的HTTP接口。
KB2：原配置授权/敏感投影下的管理与精确版本选择入口已编码；下列引用/物化规则继续实施。Agent目录目前是共享能力目录，不能把私有语料正文嵌入Agent而绕过知识库组织范围；Agent/Pipeline只保存精确引用和Hash，正文在原任务经当前授权物化时冻结，并把任务组收窄到所有来源交集。历史解释使用原任务正文，不用当前语料替换。
KB3：在原LLM调用链注入有界参考上下文，保留所用文档/版本/摘要与预算；参考资料不能替代原会话证据，评测/回放仍沿原调用与产物机制。按现有需求提供可重现的静态语料上下文，不先建设外部向量数据库；若后续需要检索后端，先接拥有服务。

各批代码/编译不代表真实SQL、角色/撤权、发布/worker或容量验收。新DDL仅随仓库交付，本批不执行共享迁移或部署。所有适用I1–I7仍保持，语音转换与ASR生成排除。

模型接入现已编码，沿原 ModelCallContext 传递经过原任务校验的类型化参考上下文，而不是接受共享配置里任意正文或客户端提供的“已校验”布尔值。语料仅选取当前节点精确引用的版本，保留库/版本/行/摘要/文档ID/来源；作为参考数据单独进入模型消息，不改变会话消息ID与引用校验。参考上下文不进入模型成本等公共元数据序列化；Token窗口与预算继续由原Model Gateway执行。历史读取/回放使用原任务信封，不读取当前知识库版本替换。两种真实适配器均消费该类型化上下文，缺少上下文、任务身份不符、单节点参考JSON超过256KiB或缺少原Gateway路径时拒绝调用。实际模型/worker/预算与容量验收仍待完成。
